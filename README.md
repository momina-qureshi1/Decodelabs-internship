# UI/UX Design Internship — Project 2: The Blueprint (Wireframing)
**DecodeLabs | Batch 2026**

## 📌 Overview
This repository contains my submission for **Project 2** of the UI/UX Design Internship at DecodeLabs. The task focused on **Information Architecture** and **low-fidelity wireframing** — not visual design — for an e-commerce homepage suffering from checkout drop-off and cluttered layout.

## 🎯 Scenario
An e-commerce brand (Aura Kicks) is losing customers during checkout due to a cluttered layout and confusing user flow. The goal was to design a clean, logical structure for the **Homepage**, focusing purely on user flow and hierarchy — no color, no imagery, no decoration.

## 🛠️ Design Constraints (per brief)
- Grayscale only — **Black, White, Grey**
- No images or color
- Clear, high-contrast Call-to-Action (CTA) buttons
- Focus on **User Flow** and **Hierarchy**, not aesthetics

## 🧠 Key Design Decisions
- **Layout pattern:** F-Pattern (best suited for content-heavy, multi-product pages)
- **Information Architecture:** Hierarchical + Sequential hybrid — global nav/search at top, page reads top-to-bottom as a guided sequence
- **CTA strategy:** 3-tier placement — primary CTA above the fold, secondary re-engagement CTA mid-page, repeatable "Add to Cart" CTA per product card
- **Reusable components:** Product cards follow one consistent structure (image, name, price, CTA) to reduce cognitive load

Full reasoning is documented in [`wireframe_rationale.md`](./wireframe_rationale.md).
