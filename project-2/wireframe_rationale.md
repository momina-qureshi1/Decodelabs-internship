# Project 2 — The Blueprint (Wireframing)
**Scenario:** Aura Kicks e-commerce brand, homepage & checkout flow — reducing friction and clarifying hierarchy.

## Information Architecture
Homepage uses a **hierarchical + sequential hybrid**: primary nav and search sit at the top (global access), the page then reads top-to-bottom as a single guided sequence — Hero → Categories → Products → Re-engagement CTA → Trust signals → Footer.

## Layout Pattern
**F-Pattern** was chosen over Z-Pattern because this is a content-heavy commerce page (multiple product cards), not a single-goal landing page. Users scan the headline, then drop vertically down the left edge of the product grid.

## CTA Strategy (3-tier placement)
1. **Above the fold — "Shop Now"**: high-contrast black button for high-intent users.
2. **Mid-page — "Learn More"**: re-engagement CTA for undecided users after they've scanned the value stack (categories + first product row).
3. **Per product card — "Add to Cart"**: repeated as a single reusable component, not redesigned per item, to keep interaction patterns consistent (reduces cognitive load).

## Key Decisions Addressing the Brief's "Frictionless" Goal
- **Search is full-width and prominent** — supports users who already know what they want (bypasses browsing friction).
- **Categories use icon shortcuts, not just text links** — faster recognition than reading.
- **Product cards are a single repeatable component** (image, name, price, CTA) — consistent structure lowers decision fatigue across the grid.
- **Whitespace is deliberate**, not empty — used to frame the search bar and product grid so the eye isn't fighting clutter.
- **Grayscale only** — per brief, no color/imagery decisions were made at this stage; only structure and hierarchy.

## Tools Used
Wireframe built to spec: Black/White/Grey only, low-fidelity, clear CTAs, homepage focus.
